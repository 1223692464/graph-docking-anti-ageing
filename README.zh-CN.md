# Graph-Docking 模型复现包

本仓库收录最终 QC 版的 Docking-only、Graph-only 和 Graph-Docking Fusion 三模型材料，以及药食同源候选库的计算预测与筛选依据。

## 本次提供的材料

- 最终三模型训练及必要的数据准备、推断脚本，仅将原始绝对路径改为可移植路径；不收录探索性脚本或重复副本。
- 分子结构和 P/U 标签、分子图张量、固定骨架划分、对接输入。
- 5 个随机种子的模型权重、预处理统计量、训练历史及训练/验证/测试预测。
- 4593 个候选的推断输入、全库预测、20 靶点评分及最终筛选证据。
- FDA 参考集、参考集推断输入和预测、阈值计算脚本。
- 4593 个候选的 Excel 预测数据库快照、7 个候选的名称表。
- 文件清单、SHA-256 校验值与可运行的输出复核脚本。

数据库网站：https://ksl.xmnk.cn。仓库提供对应的候选预测数据库快照。

## 快速核对

在仓库根目录运行：

```bash
python -m pip install numpy pandas openpyxl
python scripts/prepare_data.py
python scripts/verify_release.py
python scripts/reproduce_selection.py
```

较大的 CSV、图张量和权重采用无损 gzip 压缩。第一条脚本会解压至原文件名并校验，不需要手工改名。后两条脚本复核已有预测，不进行重新训练。

已复核的关键结果：FDA_Q90 完整值为 24.62142791748047，仅满足该阈值的候选有 941 个，同时满足四项条件的候选有 7 个。45 份预测表编号与标签、15 组测试指标均通过检查。

## 需要区分的细节

- 原始图输入实际为 P214 + U5000；QC 后两类对接模型为 P212 + U5000。不能直接写成稿件中的 P211，差异仍需核对。
- 5 个随机种子采用同一固定骨架划分，不是 5 次重新划分。
- 图分支为 GINE；图嵌入 128 维。对接原始输入为 41 维，经分支编码得到 64 维，拼接后 192 维；不是门控注意力融合。
- `positive_vote` 在实际推断代码中按 `logit > 0` 计数；当前数据没有恰为零的 logit。
- 内部字段 `6OOK` 对应显示 PDB ID `6O0K`。为兼容权重与特征顺序，内部字段没有擅自改名。
- 分类指标使用验证集选择的 F1 阈值，与候选库阳性投票的零阈值不是同一概念。
- 未恢复原训练环境的确切版本；当前只完成保存输出的数值核对，未重新训练或重新对接。
